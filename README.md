# UK Census — Predicting Development & Investment
This project was carried out to analyze and predict best development measures to be taken using the United Kingdom. 

## Data
The data used was from the 2022 census, which will advice public leaders or private professionals to determine the aspect of the town should be developed and what investment could be made to improve growth and development.

## Files
`Project code.ipynb`, `census file.csv` (link to data source; avoid large commits).

## Pipeline
EDA → feature engineering → modeling (RandomForest/XGBoost) → interpretation (feature importance/SHAP) → recommendations.

## Deliverables
- Top drivers/features
- Ranked area recommendations
